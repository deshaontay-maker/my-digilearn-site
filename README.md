# My DigiLearn site

A tiny website, built in the IT DigiLearn AI Enablement course.

## Run it on your computer

You need Node.js (the course shows how to install it).

```
npm start
```

Then open http://localhost:3000 in your browser. Press Ctrl+C in the terminal to stop it.

## Run the tests

```
npm test
```

## The course folder

The `course` folder belongs to the IT DigiLearn classes. Classes 5, 6 and 7 tell you when to run `node course/start.js` with the class number.
It makes a new branch with the change that class gives you. It never pushes.
